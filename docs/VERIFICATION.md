# 本地验证记录

验证日期：2026-10-26。使用 Playwright CLI 0.1.22 驱动 Chromium；素材解析另使用 ffprobe。

## 已验证

- 16 个独立媒体文件的 SHA-256 与原 HTML 解码数据一致。
- 两个 MP4 均包含 H.264 视频与 AAC 音频，时长分别为 56 秒、120 秒。
- 支持 HTTP Range 的本地服务下，两集章节按钮均能定位并开始播放；测试定位点为第一集 26 秒、第二集 47.6 秒。
- 六题全部选择正确答案后得分为 `6 / 6`；再次点击已答题的错误选项，得分保持不变。
- 刷新页面后分数恢复 `0 / 6`。
- 错误答案会标出错误与正确选项，并显示反馈。
- 390 × 844 视口下，页面宽度为 390，没有水平溢出；所有图片加载成功。
- 已检查封面与实机截图；静态素材路径与 README 本地链接检查通过。

## 范围与已知限制

- Python 自带简易 HTTP 服务不支持视频 Range 请求，章节定位可能回到开头或延迟；使用支持分段请求的服务后验证通过。
- 未实测 Safari、Firefox 或手机硬件，也未通过浏览器工具验证 `file://` 打开方式（工具阻止该协议）。
- 未独立复核原课件全部科普数据；未验证教学效果。
- GitHub 发布状态以远程仓库为准；本次验证未包含 GitHub Pages 部署。

运行时保留单页原生实现；仅拆出静态媒体，避免额外框架、构建和依赖，便于维护与离线分发。
